# BudgetRoute-RAG

A token-efficient, cost-aware Retrieval-Augmented Generation system.

## Objective

Build a local-first RAG system that selects the cheapest suitable
retrieval and language-model tier while maintaining answer quality.

## Planned features

- Document ingestion and chunking
- Local embeddings and vector retrieval
- Three-tier generation
- Machine-learning-based model routing
- Semantic caching
- Context compression
- Automatic escalation
- Evaluation and benchmarking
- FastAPI and Streamlit interface
